## The Impact Bullet Builder Formula

```
Accomplishment + Metric + How + Why = IMPACT
```

| Component | What It Answers | Example Fragment |
| --- | --- | --- |
| **Accomplishment** | What did you DO? (not "responsible for") | Redesigned the thermal monitoring pipeline... |
| **Metric** | How much? How many? What %? What $? | ...reducing false alarms by 74%... |
| **How** | What tools, methods, or skills did you use? | ...using Python-based anomaly detection in MATLAB... |
| **Why** | Why does the CEO care? Business impact. | ...saving $1.2M/year in unnecessary shutdowns. |

### Three Tiers of Value

- **★ "You Did What Was Asked"** (10–30) — duty description, no metric/method/outcome. Invisible to hiring managers or a promotion committee.
- **★★ "You Went Above and Beyond"** (31–60) — real accomplishment, some numbers, missing full impact chain. Gets considered.
- **★★★ "You Spread the Impact Far and Wide"** (61–100) — full formula, value reaching beyond the individual. Gets hired, or counts as strong promotion-case proof.

### Six Key Principles

1. **Personal Ownership** — flag "we/team/group/our" language; replace with the candidate's specific personal contribution.
2. **Problem Context / "So What?"** — paint the pain/problem first (stakes, before/after, scale).
3. **Accomplishments vs. Duties** — a duty describes what was assigned; an accomplishment describes what changed because the person was there.
4. **BS Meter** — no vague claims without proof.
5. **Action Verbs** — never start with "Responsible for," "Duties included," "Assisted with," "Helped with."
6. **Skills in Context** — show tools inside the bullets, not just in a list.

### Scoring System (both protocols)

8 criteria, each scored 0–10 based on the % of in-scope bullets that pass, then summed and multiplied by 1.25 for a 0–100 overall score. 0% still scores 1, not 0. Tiers: 10–30 = ★, 31–60 = ★★, 61–100 = ★★★.

## Full Client Protocol — Summary

- No CTA — this is delivery, not marketing.
- All bullets rewritten, full resume rewrite included, 5–8 key issues, 3 before/after examples, 5–8 action items, full 8-criteria scorecard.
- Voice: second person, "helpful friend who happens to be an expert" — factual, direct, never inflammatory.
- Banned words: disaster, filler, dead, kills/killer, pure filler, BS, thin, red flag, zero value. "Invisible" is allowed — it's core positioning language.
